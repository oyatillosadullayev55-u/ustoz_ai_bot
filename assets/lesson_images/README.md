# Dars rasmlari

Har bir dars uchun 1280×720 JPEG illyustratsiya. Fayl nomi dars ID siga bog'langan:

```text
lesson_<dars_id>.jpg
```

Masalan, `lesson_502.jpg` — 502-ID li "Fotosintez" darsi.

- 35 ta dars, 35 ta rasm (1101-1115 Oson Studio kurslari rasmlari qo'shilgan).
- Nisbat: 16:9.
- Fon: to'q yashil-ko'k; urg'u: feruza va amber.
- Rasmlarda matn, raqam va logotip yo'q.
- To'liq dizayn tizimi, ro'yxat va kod oqimi:
  [`docs/DARS_DIZAYNI.md`](../../docs/DARS_DIZAYNI.md).

bilan saqlang va botni qayta ishga tushiring.
