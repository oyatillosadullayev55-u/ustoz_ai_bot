✅ Xulosa

- Prompt — AI'ga beriladigan buyruq; aniqlik sifatni belgilaydi.
- RAG AI'ga hujjatlaringiz asosida javob beradi.
- Kurs kod yozishni bilmasdan ham o'rgatadi.

### Xulosa

Prompt Engineering kursida AI'ga aniq buyruq berish, RAG texnologiyasi, roll berish va javob formatini boshqarishni 37 ta darsda o'rganamiz.

   - To'g'ri javob: **Retrieval-Augmented Generation**
